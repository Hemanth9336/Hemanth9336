# Hemanth Phani Sai Mothukuri

Software Engineer at **Amdocs**. I build with **Python, SQL, AWS and CI/CD**, and I use machine learning where it solves a real decision: will it rain, when an invoice will be paid, whether a review is unhappy, or whether network traffic is an attack.

I am learning toward **applied AI and Forward Deployed Engineer** work: take a messy customer problem, ship a working system, and explain it to people who are not ML specialists. Every ML repository below is written that way — plain-English README, architecture, high-level and low-level design, model notes, and a short path from the classic model to GenAI (embeddings, RAG, agents).
